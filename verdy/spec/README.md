# spec

Versioned JSON Schemas, published as standalone specs.

| File | Describes |
| --- | --- |
| `odd.schema.json` | Operational Design Domain documents (spec `0.4.0`) |
| `stl_specs.schema.json` | STL safety-spec files (spec `0.2.0`) |
| `ontology.schema.json` | Parameter ontology trees (spec `0.2.0`) |
| `ontology_core.yaml` | The bundled `core` ontology |
| `index_v1.sql` | DuckDB evidence index schema |

The full ODD specification is in [`docs/odd-spec.md`](../../docs/odd-spec.md).
