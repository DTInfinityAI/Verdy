# Examples

| Example | Shows |
| --- | --- |
| [`home_robot/`](home_robot/) | A full evaluation on the built-in simulator: ODD, specs, a policy, and three run configs that reach `FAIL`, `PASS` and `INCONCLUSIVE`; plus the improvement loop (`improve.yaml`) that takes the failing policy to `PASS` |
| [`log_replay/`](log_replay/) | Scoring recorded runs instead of simulating new ones |
| [`scenesmith/`](scenesmith/) | Scenes generated by SceneSmith from each scenario, with Claude-written prompts (needs SceneSmith and API keys) |

Run them from their own directory, for example `cd home_robot && verdy run run.yaml`.
Reports are written to `reports/` there (ignored by git).
